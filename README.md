# Fahad Rehman — Flutter & Full Stack Developer

Personal portfolio for mobile applications, full stack product work, and anonymous engineering case studies. Built with the existing Next.js 14, React 18, MDX, and Once UI implementation.

## Local development

    npm ci
    npm run dev

## Validation

    npx tsc --noEmit
    npm run build

The existing template disables type and ESLint checks inside the build, so run TypeScript separately. Content lives in src/app/resources/content.js; case studies live in src/app/work/projects.

## Content and privacy

Use the actual role and employment dates reflected on LinkedIn. Keep confidential client and product names out of case studies. Publish verified outcomes; do not imply revenue, user growth, or time savings without evidence. Project links must lead to corresponding source or demos; private work uses case studies without misleading external links.
